# MYPORTFOLIO

A modern personal portfolio website built with HTML, CSS, and JavaScript.

## Overview

This project is a responsive portfolio landing page showcasing:

- A home/hero section
- About information
- Skills and technologies
- Work experience timeline
- Project highlights
- Contact section
- Theme toggle support
- Mobile-friendly layout

## Live Demo

https://vandita18.github.io/MYPORTFOLIO/

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Boxicons

## Local Development

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` directly in a browser, or serve it locally:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deployment

This portfolio is configured for GitHub Pages deployment from the repository's `main` branch.
